# Predicting-Terrorist-Attacks-in-the-US-
Used an ARIMA ML model to predict Terrorist Attacks in the US from 2025-2040. 

● Implemented an ARIMA time-series forecasting model on 49 years of Global Terrorism Database data, 
achieving 37% predictive accuracy for annual U.S. incidents. 

● Queried and cleaned a 135-feature, 2,774-record dataset using MySQL and Python, performing data cleaning, 
transformation, and feature optimization to improve model performance.
